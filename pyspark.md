# Spark Cheat sheet

## how to create a sparkSession: 

```python
from pyspark.sql import SparkSession
spark = SparkSession.builder \
        .appName("Example") \
        .getOrCreate()
```

## how to create a rdd and its function

### from existing collection

```python
data = [10, 20, 30, 40, 50]
rdd = spark.sparkContext.parallelize(data)
```

### from external source

```python
rdd = spark.sparkContext.textFile("input.txt")
```

### applying a transformation 

```python
rdd2 = rdd1.map(lambda x: x * x)
```

### filtering an rdd

```python
even_rdd = rdd.filter(lambda x: x % 2 == 0)
```

### flatMap trnasformation

```python
words = lines.flatMap(lambda line: line.split())
```

> Consider the input: **{“big data”,“apache spark”}**.  
Using map() with a split operation may conceptually produce: **{[big, data], [apache,spark]}**.  
Using flatMap() produces: **{big, data,apache,spark}**

## actions

### count()  
returns the number of elements in an RDD
```python
n = rdd.count()
```
### collect()  
 returns all elements of an RDD to the Driver
```python
rdd.collect()
```
### first() 
 returns the first element of an RDD
```python
rdd.first()
```
### take()  
 returns a limited number of elements.
```python
rdd.take(5)
```
### reduce()  
aggregates the elements of the RDD using a specified commutative and associative binary operator.
```python
rdd.reduce(lambda a, b: a + b)
rdd.reduceByKey(lambda a, b: a + b) # returns as a new rdd
rdd.reduceByKeyLocally(lambda a, b: a + b) # returns it as python dicitionary
```
### saveAsTextFile()  
```python
rdd.saveAsTextFile("path/to/output_directory")
```

# Spark SQL 
## Spark SQL & Advanced DataFrame Operations
### Viewing the Schema
Displays the column names, data types, and nullability of a DataFrame.
```python
salesDF.printSchema()
```
### Creating a Temporary View
Registers a DataFrame as a temporary table-like view so it can be queried using SQL.
```python
salesDF.createOrReplaceTempView("sales")
```
### Executing a SQL Query
Runs a declarative SQL query against a registered temporary view and returns a new DataFrame.
```python
resultDF = spark.sql("""
    SELECT City, SUM(Amount) AS TotalSales
    FROM sales
    WHERE Amount > 10000
    GROUP BY City
""")
resultDF.show()
```
### Inspecting the Execution Plan
Displays the logical and physical execution plans generated by the Catalyst Optimizer.
```python
resultDF.explain()
# For detailed plan information (parsed, analyzed, optimized, and physical plans):
resultDF.explain(True)
```

## Advanced Spark Programming
### Caching and Persistence
Retains reusable intermediate datasets in memory or disk across multiple actions (evaluated lazily).
```python
# Cache using the default storage level
highValueDF.cache()

# Persist with explicit storage level control
highValueDF.persist()

# Remove persisted data from memory/disk when no longer needed
highValueDF.unpersist()
```
### Broadcast Variables
Efficiently distributes read-only lookup tables or reference data to all worker nodes.
```python
categories = {
    "P101": "Electronics",
    "P102": "Furniture",
    "P103": "Clothing"
}
broadcastCategories = spark.sparkContext.broadcast(categories)

# Accessing the broadcast value inside tasks
broadcastCategories.value
```
### Accumulators
Aggregates diagnostic counters or metrics contributed by distributed tasks back to the Driver.
```python
badRecords = spark.sparkContext.accumulator(0)
```
### Partition Management
Adjusts the number of partitions to optimize parallelism or reduce scheduling overhead.
```python
# Redistributes data across a specified number of partitions (triggers a full shuffle)
newDF = salesDF.repartition(8)

# Reduces the number of partitions while minimizing data movement
smallerDF = salesDF.coalesce(2)
```

# Spark ML (DataFrame-based `spark.ml` API)
## Core Concepts & Methods
| Component / Method | Description |
| :--- | :--- |
| **Transformer** | Converts one DataFrame into another DataFrame (e.g., `VectorAssembler`, fitted `Model`). |
| **Estimator** | Machine learning algorithm that learns parameters from training data to produce a `Model` (e.g., `LogisticRegression`, `KMeans`). |
| `transform()` | Method called on a `Transformer` or fitted `Model` to generate a transformed DataFrame or predictions. |
| `fit()` | Method called on an `Estimator` or `Pipeline` on training data to produce a fitted `Model` or `PipelineModel`. |
## Feature Vector Construction (`VectorAssembler`)
Combines multiple predictor columns into a single `features` vector column required by Spark ML algorithms.
```python
from pyspark.ml.feature import VectorAssembler

assembler = VectorAssembler(
    inputCols=["Age", "Income", "Visits", "TimeSpent"],
    outputCol="features"
)
preparedDF = assembler.transform(customerDF)
```
## Splitting Data (Train / Test Split)
Randomly splits a DataFrame into training and testing subsets using specified weights.
```python
trainDF, testDF = preparedDF.randomSplit([0.8, 0.2], seed=42)
```
## Classification (`LogisticRegression`)
Trains a classification estimator on `trainDF` and generates predictions on `testDF`.
```python
from pyspark.ml.classification import LogisticRegression

lr = LogisticRegression(
    featuresCol="features",
    labelCol="label"
)
model = lr.fit(trainDF)
predictions = model.transform(testDF)
```
## Clustering (`KMeans`)
Trains an unsupervised k-means clustering model to group observations into $k$ clusters.
```python
from pyspark.ml.clustering import KMeans

kmeans = KMeans(
    featuresCol="features",
    k=3,
    seed=42
)
model = kmeans.fit(dataDF)
predictions = model.transform(dataDF)
```
## Machine Learning Pipelines (`Pipeline`)
Chains multiple `Transformers` and `Estimators` into a single reproducible workflow.
```python
from pyspark.ml import Pipeline
from pyspark.ml.feature import VectorAssembler
from pyspark.ml.classification import LogisticRegression

assembler = VectorAssembler(
    inputCols=["Age", "Income", "Visits"],
    outputCol="features"
)
lr = LogisticRegression(
    featuresCol="features",
    labelCol="label"
)

# Define pipeline stages
pipeline = Pipeline(stages=[assembler, lr])

# Fit the entire pipeline to produce a PipelineModel
pipelineModel = pipeline.fit(trainDF)

# Apply consistent transformations and predictions to test data
predictions = pipelineModel.transform(testDF)
```
